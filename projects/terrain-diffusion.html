Origin

This project was lead by Cayden Wong, and in his words, I state the project:

Background Some games like Minecraft use a seeded, deterministic method of generating terrain that can span infinitely in all directions, often powered by some sort of noise algorithm (perlin noise) that can create terrain like shapes. However, often these are distinctly game-like and miss the realism that real world terrain carries. On the flip side, AI image generators are able to create “realistic” looking terrain that is much more akin to real world geography. However, they are limited by the size constraints of modern (image diffusion) models, which typically generate images of a fixed bounded size. In December of 2025, a paper was published that combined the two methods, allowing for seamless infinite generation of images using a diffusion based image generation model. Goal One specific use case highlighted by this paper was its applications in realistic terrain generation. The goal of this project is to reproduce that result. Specifically, how can we create realistic terrain heightmaps from a fixed seed that span infinitely across a 2D plane using constant memory? Then, how can we render these heightmaps in a 2D/3D web environment? Importantly, we will NOT be retraining model weights for the diffusion model, instead the focus is on reproducing the model pipeline and rendering the final product. We will focus on these objectives: Loading a pre-trained model and generating elevation encodings Implementing the blended window sampler to generate adjacent encodings Managing backend requests for encodings given a specific region and seed from the frontend / CLI Rendering encodings in an interactive 2D/3D environment
